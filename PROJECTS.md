## How entries get here

Add an entry when there is a real artifact to point to. Use a plain-language name, one sentence about what it does and, for public work, a verified link. Update an existing entry when the build changes. Private builds use a reviewed description and no source link.

The GitHub calendar measures qualifying activity across my GitHub account. The separate Codex calendar measures recorded Codex usage. A Codex session by itself does not create a GitHub contribution.
